Someone built the instrument.

Tone.js is a library: a box of functions other people wrote. You call them without knowing how they make sound. That's the coffee machine from this morning.

Call it, then write your own · A minute of music

  
Notes, for non-musicians

  

    

      

      
Click a key to hear it and see its name.

      
A note is a letter from A to G, then a number for the octave. "C4" is middle C; "C5" is the same note, one octave higher. The black keys are sharps: "C#4" sits between C and D.

    

    

      
How long: click to hear each length

      

      
A beat lasts half a second here. Lengths are fractions of four beats: "4n" is a quarter of four beats, so one beat.

    

  

  
For students who have never read music. Three things only: notes have letter names A to G and repeat every octave; the number says which octave (C4 is middle C on a piano); lengths are written as fractions of a four-beat bar, and at Tone.js's default speed (120 beats a minute) a beat is half a second. Play C, E, G for them: that's a chord. Tip for the room: notes from one chord (C, E, G) or the white keys alone rarely sound wrong together.

One synth, one voice

  

    
01A synth plays one note at a time, like a singer. It can't start two notes at the same moment.

    
02Code runs top to bottom, and fast: three lines take less than a millisecond.

    
03Unless you say when, a call to triggerAttackRelease means "play this note now".

Ask for a show of hands before anyone clicks; point back at the three facts on the last slide. Each line schedules a note for "now", and the three lines run within a millisecond. The synth has one voice, so when the second note asks to start at the same moment, Tone.js stops the scene: Error: Start time must be strictly greater than previous start time. Everyone will meet this error today, so read it aloud. The fix is the third argument: when to play, in seconds after you press Play. 0 is right away, 0.5 is half a second later. (In this deck's editors a time counts from the moment you press Play. In plain Tone.js you'd add the current time, Tone.now(), which needs a variable; that's Thursday.)

Black track · Exercise 4

  
Write your song

  

  
The main black-track exercise, and most people's whole block. Sections take a start and play from it; song() calls them with starts two seconds apart. The check calls verse(100) and chorus(100) silently and makes sure every note is timed from start (a note at a fixed 0.5 gets caught). Common snag: two sections with the same start, which gives the "strictly greater" error. The song is saved in the browser for every lecture, so on Thursday (Data) it comes back and gets data fed into it.

Advanced room · Exercise 7

  
Let the sections keep time

  

  
Sections of different lengths, chained by their return values. The check calls verse(100) and chorus(100) silently and looks at what they give back: a section that forgets to return is caught here, as is a return that isn't later than the start. Push early finishers to a bridge of an odd length (1.5 seconds) to prove nothing in song() needs to change.

Advanced room · Exercise 8

  
Pass the function. Don't call it.

  

  
Advanced room only: buttons are Monday for everyone else. makeButton is a helper written for this slide; real web pages do the same thing with button.addEventListener("click", kick), which is next Monday. The big idea: kick is the function; kick() is calling it right now. A button needs the function itself so it can call it later, on every click.
