10:35. Before any syntax. Five volunteers stand in a line at the front, each holding a note on
          a sheet of paper (C4, E4, G4…). They are the array; their place in the line is their index. Count from zero,
          out loud, down the line: "zero, one, two…". Then act out the operations on real bodies: push: someone new
          joins the right-hand end. pop: the right-hand person leaves. unshift: someone joins the left-hand end, and
          everyone's number goes up by one. shift: the left-hand person leaves, everyone shuffles down. After each move
          the room calls out each person's new number. The shuffle is the point: adding or removing at the front moves
          everyone else; at the end nobody else moves. Ask: if the line was 1000 people long, which end would you rather
          work at? This slide names the four moves and which end each works on, so the picture and the words land
          together. Keep the line (and the floor marks) in mind: after the break, the loop walks this exact line.

Walking the line

        

        
Off by one: the line walks itself

        

          

            
01The line. Six to eight of you, each holding a value card, standing on the floor marks 0, 1, 2…

            
02The Counter stands at one position at a time, and only moves when the rule says so.

            
03The Caller says what to do at each position: "high-five if your value is greater than five".

          

          

            
the rule

            
four rounds

              
    
                
  1. Build the line. Everyone says their position and value.
    2. 
                
  2. Walk it with i < length.
    3. 
                
  3. Walk it with i <= length. Where does the Counter end up?
    4. 
                
  4. Step by two. Or walk it backwards.
    5. 
              

            

          

        

        
11:20–11:30. The Off By One activity. Reuse the line of people from Part 1 if you can, so it's
          visibly the same array, now with value cards (numbers). Floor marks 0, 1, 2… Two rotating roles: the Counter
          and the Caller. Round 1: build the array; each person announces their position and value; confirm the first
          person is 0, not 1. Round 2: read the rule aloud: the Counter starts at 0, checks "is i less than the length?",
          the Caller calls the operation and the line does it, then the Counter steps on. Round 3: break it with
          i <= length: the Counter walks off the end into empty space, "position 6: nobody here! undefined!". Fix it
          back. Round 4: step by two, or walk backwards, to show the Counter is only following a rule. Thirty-second
          debrief: why is the first person 0? What exactly broke with <=? What is the Counter, in one sentence?

The for loop · Time

        

        
The loop doesn't wait

        

          

            

            
melody.js

            

            

          

          

            
The whole loop runs in a blink, long before the first note has finished. It doesn't play the notes one by one: it tells Tone when to play each one.

            
With four notes and i * 0.4, when does the last note start?

            

            

          

        

        
Why a melody is a melody and not a chord: the notes are spaced out. Take the start time away
          and play: all four notes start at the same moment, because the loop finishes in microseconds. The loop doesn't
          wait between passes; Tone waits, because we told it when. i grows by one each pass, so each start time is
          pushed later by the same amount. The last note is i = 3, so it starts 3 * 0.4 = 1.2 seconds after now. Common
          wrong answer: 1.6 (counting four steps, not three: the first note starts at 0). That's an off-by-one too.
