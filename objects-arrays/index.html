Both give back "C4", and both can change it. With brackets, the label is a string, in quotes.

          

          

            

              
later · when only the program knows the label

              

            

            
When the label is in a variable, only brackets work. The dot looks for a label literally called part.

          

        

        
Use the dot when you know the label as you write. Keep the brackets in mind for later.

        
Keep it light: the same reach, different syntax, and move on. Why it earns its place now: later, when the label isn't known until the program runs (which key was pressed, which setting the player picked), the dot can't do it and brackets are the only way. Seeing it now means it won't come out of nowhere then. Arrays use the same square brackets with a number: notes[0]. That's not a coincidence.

The reveal that reframes the week: the synth they've played since the first group session is itself an object. Three things, in order, and the contrast between them. synth.oscillator: a property whose value is another object, which is why it's synth.oscillator.type: two dots, two hops. One line only; don't unpack the audio graph. synth.oscillator.type: a plain string you can read and change, exactly like person1.program = "IDB". That's a method, and they've been calling one all week. This is the one new idea: a property's value can be a function. Note: this is a plain Tone.Synth. The PolySynth in the A1 template plays several notes at once and has no single oscillator to point at (there it's synth.set({ oscillator: { type: "square" } })). Destructuring and scope are Monday's.

Wrap-up

          
By position, or by label.

          
Array: many of a kind, reached by position. Object: one thing, reached by label. An array of objects: position, then label.

          
{ }person1.firstNametone["note"]person1.program = "IDB"synth.oscillator.typesteps[0].notesteps[i].duration

        

        
Summarise: an object groups the facts about one thing and you reach them by label, with a dot or with brackets; assigning to a label changes it, or adds it if it wasn't there; a property's value can be another object or an action (a method); and an array of objects puts position and label together.
