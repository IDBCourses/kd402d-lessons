Variables: the idea · Meaning

Same number, different jobs

Quantityhow many, how much
24

Pieces from one onion. 180 grams of onion. Adding them or doubling them makes sense.

Orderwhich place
3

Step 3 of the chopping: after 2, before 4. Step 2 plus step 3 doesn't mean anything.

Rankinga judgement
5

Five for clean chopping, three for middling, one for a real mess. An opinion, written as a number.

The meaning isn't in the number. It's in how we use it and what we call it.

Short discussion. Quantity answers "how many / how much", and arithmetic on it makes sense. Order marks a place in a sequence: adding step numbers is nonsense. Ranking is a judgement on a scale. The punchline sets up naming later: a 5 alone tells you nothing; a box called "rating" tells you a lot.

    Four kinds of value, for now
    
  
    
    
    string"red"'step 2'Text. Always inside quotation marks, double or single.
    
    
    number243.5-2Plain digits, no quotation marks. Whole or decimal.

    Storing is half the job.

    Working with data · Type coercion
    
  
    JavaScript quietly changes the type
    
  
    When an operation needs a different type, JavaScript converts the value for you, without asking. That's called type coercion. Click to see what happens.
    
  
    
  
    The first time the word gets real weight. "5" + 3: + with a string glues, so 3 becomes "3", result "53". "5" - 3: minus only does maths, so "5" becomes 5, result 2. It matters because text from an input field is always a string: "24" + 1 is "241". NaN means "not a number": a sum that couldn't be done.
