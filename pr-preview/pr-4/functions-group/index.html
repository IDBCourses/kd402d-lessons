Scene 02 · Call it, then write your own · 13:30

Someone built the instrument.

Tone.js is a library: a box of functions other people wrote. You call them without knowing how they make sound. That's the coffee machine from this morning.

45 minutes of work time in this block. A library is functions someone else wrote and packaged up for us. We only need to know what to pass in and what happens; that's abstraction.

Ask for a show of hands before anyone clicks. Most people expect one after another, because code runs line by line. It does run line by line, but each line only schedules a note for "now", and the three lines run within a millisecond. A Synth plays one note at a time, so when the second note asks to start at the same moment, Tone.js stops the scene: Error: Start time must be strictly greater than previous start time. Everyone will meet this error today, so read it aloud. The fix is the third argument, a time: Tone.now() is the current time in seconds, and now + 0.5 is half a second later.

The point of return this afternoon. verse plays its notes and hands back the time it finishes. song keeps that in t and passes it into the next section. Pretend Tone.now() is 0 so the numbers are readable. Note the let: t changes, so it can't be const. Ask: what would t be if verse forgot to return? (undefined, and the next notes fail.)

Blue track · Exercise 5

  
Wrap the long call in a short one

  

  
Wrapping: your own short function around someone else's long one. It's abstraction again, but now they're the ones hiding the details. A second instrument (MembraneSynth, a drum) shows why wrappers help: the song reads as note and kick, not as two kinds of triggerAttackRelease.







  Your turn
  
Blue track · Exercise 6

  
Pass the function. Don't call it.

  

  
makeButton is a helper written for this slide; real web pages do the same thing with button.addEventListener("click", kick), which is next Monday. The big idea: kick is the function; kick() is calling it right now. A button needs the function itself so it can call it later, on every click.

Purple track · Exercise 7

  
Four ways to write the same kick

  
Name each style. Every one of them can be cued with kick(now), except the last, which has no name.

  

  

  
Declaration, function expression, arrow function, anonymous function. Monday's lecture goes deeper into declarations vs expressions; this is a first look. One difference worth naming: declarations can be called before the line they're written on (hoisting); expressions and arrows can't. Try it in the workspace.

Send a function into a function

  

  
twice takes a section, which is a function, and calls it. The tests don't use sound: they pass a tiny function of their own that adds 1 to the time and counts how often it was called.
