Version control · On your feet

Let's enact commits!

About 20 minutes on your feet. One way to run it: each student who joins the front of the room is a commit, holding a sticky with a short message saying what changed; they line up in order, so the line is the history. "Undo" means walking back along the line to an earlier commit. A second line in another corner is GitHub: pushing copies the new commits across, pulling copies them back. Finish by naming what they acted: commit, history, push, pull.
Version control · Words for today · 11:05

Six words

repositoryA project folder plus its whole history. "Repo" for short.
cloneCopy a repo from GitHub onto your laptop.
commitSave a snapshot of your changes into the history, with a message.
pushSend your new commits from your laptop to GitHub.
pullBring new commits from GitHub down to your laptop.
forkMake your own copy of someone else's repo, on GitHub, under your account.
Tie each word back to the enactment: who was the commit, what did pushing look like. Fork is the only one they didn't act; it's next. Leave this slide up while you switch to Git vs GitHub if people are still writing.
Version control · Two different things

Git is not GitHub

Git
A tool on your laptop

Keeps the history of a folder. Works offline. VS Code uses it behind the scenes.

GitHub
A website

Hosts copies of repositories online, so you can back them up, share them and work together.

The most common confusion of the day. Git works without the internet and without GitHub; GitHub is one of several sites (GitLab, Bitbucket) that host Git repos. In the enactment, the line at the front was Git on your laptop; the line in the corner was GitHub.

Commit and push · Once per TODO

Commit and push each TODO

1Do one // TODO in script.js. Save.
2Open Source Control (left bar, the branch icon). Click the file to see the diff.
3Write a message that says what changed.
4Click Commit.If it asks to stage all changes, say Yes.
5Click Sync Changes to push.

Then repeat

Next TODO → same loop. One commit per change, not one big one at the end.

Troubleshooting T or Esc to close

No GitVS Code doesn't include Git. Mac: run git --version and accept the Command Line Tools install. Windows: install Git for Windows, then restart VS Code.
"Please tell me who you are"Run git config --global user.name "Your Name" and git config --global user.email "you@example.com". Use your GitHub email.
Push asks for a passwordSign in through VS Code's GitHub prompt instead. GitHub doesn't accept your account password for Git.
Repo is in OneDrive / iCloud / DropboxMove it to a plain local folder, e.g. Documents/code, and open it from there.
Push fails with a permission errorYou cloned the course repo, not your fork. Clone again and pick your-username/kd402d-exercises.
Nothing in the consoleOpen the page in your browser and open dev tools (Chrome: ⌥⌘J / Ctrl+Shift+J).
