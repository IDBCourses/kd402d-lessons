Done whenyour console logs normX from 0 to (nearly) 1, whatever the window size, and normY too.

  
The right edge reads the window's width in pixels, minus one, so it changes with the window. Divided by innerWidth it's 0.999 at the right edge on any screen. normY is 0 at the top and 1 at the bottom: clientY counts down. Common mistake: dividing clientY by innerWidth, which goes above 1 on a wide screen.

Done whenspeeds.length stops at 10, and the note bends more smoothly than in block 3.

  
Without shift the list grows by about 60 a second. With it, each new speed is a tenth of the average, so one jumpy value can't throw the pitch around. pop() would remove the newest: the opposite of what we want. Averaging everything (the morning's version 1) gets sluggish because one new speed counts for 1 in thousands.

Done whenflicking and stopping lets the note settle back within half a second, with no NaN in the console.

  
Every speed has the same lifetime and they arrive in order, so the one leaving is always at the front: shift. useAverage must run from forgetOldest too, or the sound only changes when you move. An empty list gives 0 / 0 = NaN, which the synth refuses: let average = 0; if (speeds.length > 0) { … }. setTimeout(forgetOldest(), 500), with brackets, calls it straight away. 100 ms is twitchy again; 2000 ms swells and is slow to settle. Commit at the end of block 4.
